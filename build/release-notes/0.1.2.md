kyclaw 0.1.2

本次更新内容：

对话

- 长思考的**内滚**现在自己跟着走：思考框正文限高后自己滚，此前外层消息列表的跟随管不到它，表现为「想了一半就不动了」；现在它与消息列表同一套口径（贴底才跟随、上翻暂停、自己滚回底再贴上），布局变化（第一次溢出、折叠重开、换一段、窗口 resize）只纠正位置、不改阅读位置。
- 一条回复里的思考与工具调用收成一块（头部是「使用 N 个工具」）：**这一轮跑完自动收起**；你手点过开合就听你的，不再被自动开合覆盖。一段思考后面已经出现别的内容（工具行 / 正文 / 下一段思考）时，这一段自己收起来让版面（只收一次，之后听你的）。
- 工作区还没确定时，输入区的权限入口**仍然看得见**；点它只会**提示前往设置**，**不会擅自替你切换权限**。
- 浅色 / 深色两套主题下的边框对比增强：细边统一为 **1px** 的发丝线。
- 修了一个冷启动偶发的输入丢失：刚打开应用、会话还在准备的那几秒里敲的字，个别情况下会在准备完成的一瞬间被吞掉（发送钮一直点不动）；现在会原样带进会话。同一处也收紧了边界：这些字**只属于当前会话**，切到别的会话或新建会话时不会跟着带过去。

记忆

- 设置页「记忆」现在是**两张独立卡片**：第一张是语义召回设置 + 「记忆空间」入口（打开弹窗）；第二张是**记忆指令**（全局与项目两份偏好，编辑器在二级弹窗里）。左列菜单里只有「记忆」一项，不再单列「记忆指令」（旧的 `/settings/rules` 深链会转到这一栏）。
- 「记忆空间」另有独立页（`/memory`）。两个入口看到的是**当前活动会话**那一份：切会话自动重拉，保存 / 清空写的就是它；草稿会话按「没有会话」处理（不给编辑入口）。

文件预览

- 图片：除常见光栅格式外，新收 **SVG** 与 **ICO**；SVG 按纯图片渲染，不执行里面的脚本。
- **HTML**：`.html` / `.htm` 在**隔离 frame** 里预览（自带最严 CSP，脚本、外链、表单、远程资源全禁）；只有清洗过的文档才进 frame，源文件的元素不进应用自己的页面。
- **数学与 frontmatter**：markdown 里的 `$…$` / `$$…$$` 用 KaTeX 排版（样式与字体随包）；frontmatter 单独成一块展示，不混进正文。
- **文本分页 + 可见时刷新**：长文本按页读；文件在磁盘上被改时，**只在窗口可见且这个预览在前台**才去探一次版本（不可见就不轮询）。变了以后**尽量不打断阅读**：没上翻、已加载范围不大时**自动刷新到最新**；正在读、或已加载较多页时**只提示「文件已在磁盘上更新」**，由你点「重新读取并回到这里」——重读会把你放回刚才的阅读位置。
- 表格（`.xls` / `.xlsx` / `.csv` / `.tsv`）：右栏预览换成真正的只读表格（多工作表可切），解析放在后台线程，大文件不把界面卡住；旧版 `.xls` 直接读，不必先另存。
- 办公档（`.doc` / `.docx` / `.ppt` / `.pptx`）：**按页看真版式**（图片、表格、排版都在）—— 用随包的 LibreOffice 在本机转成 PDF 再显示。旧版 `.doc` / `.ppt` 以前只有一句「请另存为」，现在也能直接看。切文件或关掉面板会**真的取消**在跑的那一趟转换（引擎停掉，不是「不再看回包」）。
- 缺字体提示：转换时若缺少文档要求的字体，会如实说明「预览的版式可能与原文档不同」。
- Agent 读取：`read` 现在能直接读 **8 种**：`.doc` / `.docx` / `.xls` / `.xlsx` / `.ppt` / `.pptx` / `.csv` / `.pdf`。启用宏的（`.docm` / `.xlsm` / `.pptm` 等）、模板与放映变体（`.dotx` / `.ppsx` 等）、`.xlsb` 一律**明确拒绝**，并说清「是什么 / 为什么不读 / 下一步」，不假装支持。

更新

- 更新源是「配一次就不动」的次级设置，默认收起：页面上只留一行「更新源 + 配置」，地址输入、保存与内置源提示都在展开区（收起再展开，没保存的草稿还在）；版本、状态、更新内容与报错**常显**。
- 「关于」新增常驻的「更新日志」入口：读**随包**的这一版发行说明，所以断网、已是最新、没配更新源时都看得到「我现在装的这一版改了什么」。检查更新拿到的说明仍按纯文本显示（源上给的 HTML / 脚本按字面展示，不插进页面、不拉远程图片）。

模型

- 修了一个兼容性问题：发给兼容端点的 prompt 里，system 消息现在**归并成唯一一条、放在最前面**（此前可能有多条 system 混在消息中间，个别端点会因此报错或行为异常）。归并默认开着，`KYCLAW_SYSTEM_FIRST=0` 可以关掉（只在确认某个端点不接受单条 system 时才需要）。

如实说明的边界

- 办公档转 PDF 依赖随包的 LibreOffice：**源文件 32 MiB**（预览这条路的输入上限）/ **产出 PDF 32 MiB** / **单次 120 秒**是硬上限；这台机器上没有随包引擎时如实说「转不了」，不会假装转过。转换失败会分门别类说原因（文件坏了 / 太大 / 超时 / 任务排满 / 文件在转换期间被改了 等），不混成一句「失败」。
- **宏与字体**：转换时随包引擎按配置禁用了脚本 / 宏执行 —— 这是配置层面的阻断，**不等于**对每一次转换做过「宏确实没运行」的运行时实证（带宏的文件能照常转出结果，但那只说明「能转」，不构成宏安全的证明）。缺字体提示目前只对 OOXML 一类（`.docx` / `.pptx` 等）能给到；旧版 `.doc` / `.ppt` 那里显示为空**不代表**字体齐全。
- **表格预览不显示工作簿里的图表、图片、形状与条件格式**（认得出来就如实列出，并提示用本地应用打开获得完整体验）；公式只显示文件里存下来的结果、不回算，结果缺失时会明确提示。
- `read` 的 PDF 只抽**文字层**：**没有 OCR** —— 扫描件 / 纯图 PDF 读不到字就如实说「没有文字层」并给下一步，不假装认出来了。
- 表格预览与 `read` 是两条口径：预览走「原始字节 → 渲染端自己解析」，`read` 那边的 `.csv` 有专门的表格读法，两处行为不同是刻意的。
