kyclaw 0.1.5

本次更新内容：

Office（Excel / PowerPoint / Word）

- **错误可见（PB-023）**：打不开的文件不再静默停在骨架——docx / pptx / xlsx 都走统一的错误通道并给人话提示；明显损坏的文件（ZIP 头不对）在 **≤1 秒**内报错；打开后 10 秒仍未就绪会超时提示，不再无限等待。
- **状态栏与能力说明（PB-020）**：状态栏补全（xlsx 显示文件大小、pptx 显示幻灯片页数）；能力说明改为一次性提示，收起后可从状态栏重新打开；AI 面板在没有可用上下文时给诚实空态，不再假装有内容。
- **Excel 查找（部分）**：查找**入口已接入**，但真机点击暂不可用（已知问题，下个版本修复）。**工具组标签**：命名已统一，真机 DOM 不可直接观测 —— 这两项都不写成「已完成」。
- **编辑面视觉（PB-020 A 类，xlsx / pptx）**：工具条去掉「悬浮胶囊」，改为与 docx ribbon 同一套扁平带（圆角 0 / hairline 底 / `--bg-primary`）；按钮 26×26、r6、12px，hover/active 走 token；深色下工具条、公式栏、名称框、表标签、备注面板全部跟 token 翻档（**画布 / 白纸 / 幻灯片保持文档原色**）；名称框与公式栏 28 高 / r8 / field token / mono 12，焦点改为暖灰 `--focus-ring`（去掉包内蓝色）；能力说明行 12/18、单行省略、`title` 带全文。
  - 未覆盖：pptx 缩略图轨在当前只读/单页视图里没有对应 DOM 节点，选中态蓝框因此未覆盖；工具条分隔线在现有 DOM 里未命中（不影响观感）。

Mindmap（Pele 导图，PB-024）

- 左侧边栏新增入口与 `/mindmap` 路由：**左侧 Mermaid 文本、右侧实时渲染**（`pele@1.6.0`，MIT，按需注册）；自带示例与新建；本地单文档持久化；AI 协作先给诚实占位。
- **是 Mermaid 渲染器 + 文本驱动**：本版**没有节点拖拽 / 连线编辑器**（那需要单独实现，不在本版范围）。

启动与加载

- **加载骨架（PB-019）**：Office 打开过程有骨架与状态提示，不再白屏干等。
- **Office 预热（PB-017）**：取消「没用过 Office 就延迟 12 秒再预热」的门控，应用启动首帧后即预热字体；预热按真实 paint 记录起步，500ms 上限兜底，失败做一次有界重试。

打包

- **减包（PB-016，0.1.4 起生效）**：asar 继续排除 sourcemap / 本地建站目录 / tsbuildinfo；打包冒烟闸门保持「Office 面 6 个 wasm + pdfjs/xxhash 5 个依赖 wasm 按包目录」。
- **新增依赖**：`pele@1.6.0`（MIT），渲染器按需加载，构建产物 chunk 约 90 kB。

如实说明的边界

- **e2e 未跑**：本版发布前只跑了 typecheck、单元测试与打包态冒烟（5 条预览/关于/终端 + `/mindmap` 能渲染出 SVG），**完整 e2e 套件没有跑**，回归风险自担。
- **PPT 侧结构化能力未做**：本版 Office 的功能够改集中在错误可见、xlsx 查找/状态栏、pptx 页数与备注视觉；母版 / 动画 / 图表编辑仍只读。
- **视觉 A 类为部分落地**：xlsx / pptx 的 A-01～A-05 已生效，并有浅/深 × 1440/1100 截图与计算样式采样；pptx 缩略图轨与工具条分隔线未覆盖（见上）。
- **真机验证待补**：视觉与错误路径的真机交互回归将在发布后补做；本文件不把它们写成已逐一验证。
- **安装包体积**：asar 实测 **263.88 MiB**（0.1.4 为 261.75 MiB，+2.13 MiB）；其中 pele 依赖 2.14 MiB（416 文件）、Mindmap 渲染 chunk 约 89.2 kB，其余是 0.1.5 的 Office/导图功能代码。
