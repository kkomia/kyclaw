kyclaw 0.1.4

本次更新内容：

对话

- **工具汇总行**：过程区最后的汇总行在**结束态无条件出线**，不再等分节或折叠才画分隔线；分隔线的颜色、字号与行高与对话正文同一套声部。
- **读数统一**：权限 / 模型 / 推理强度 / 上下文这四处读数统一为 **13px 字号、500 字重、20px 行高**（sans），与正文的三声部口径一致。
- **输入区**：输入卡改为 14px 圆角的单行（36px）形态，高度在 38—180 之间随内容自适应并整体贴底；发送键回到卡内右侧（26×26 单上箭头）；**权限 / 模型 / 推理强度 / 上下文（contextChip）移到卡外一行**，按组排布，不再挤在输入框内部。
- **模型 / 强度触发器**：展开态不再铺 hover 底色、只留文字墨色；两个触发器的对称内距（px-1）与组间距（gap-0）对齐，hover 背景里的文字居中。
- **自绘光标与文字对齐**：镜像层对齐 textarea 的排版（py7 / pl14 / pr9 / 14px / 行高 24），行盒按 half-leading 居中；长文本出现滚动条时镜像层宽度跟随 `textarea.clientWidth`，避免滚动条槽把光标带偏；滚动时按可视坐标钳进内容盒、滚出即隐藏；行尾换行补零宽空格，**空行的光标也能量到可见高度**。

Office

- **预热改为启动即启**：取消「没用过 Office 就延迟 12 秒再预热」的门控，应用**启动首帧后立即预热**字体；预热按真实 paint 记录起步，并以 500ms 上限兜底；失败时做一次有界重试，且重试可被真实打开的 Office 面取消。

打包

- **安装包体积**：asar 排除三类过程产物 —— sourcemap（`**/*.map`，实测 5,136 个 / 140.66 MiB）、本地建站目录 `website/`（9 个 / 0.57 MiB）、TypeScript 增量缓存（`*.tsbuildinfo`，1 个 / 0.49 MiB）。在实测 404.70 MiB 的 asar 上，这三类合计 141.72 MiB；**按算术推算出包后约为 263 MiB，本版没有重新打包，最终体积以实际产物为准**。
- **打包冒烟闸门**：装出来的 asar 里，Office 面 6 个 wasm 继续按数量钉住；另外给 pdfjs（`quickjs-eval` / `openjpeg` / `jbig2` / `qcms_bg`）与 xxhash 共 5 个**依赖自带**的 wasm 补了「名字 + 所属包目录」基线（含 pnpm 的 `.pnpm/<包>@<版本>` 深路径）——别的包目录里出现同名文件不算命中；依赖 wasm 即便被收进渲染端，也不会把 Office 计数顶成 7。

本次一并包含（0.1.3 之后）

- 本次发布同时包含 0.1.3 之后的其他产品改动：Office 三件套接入 BetterOffice（XLSX / PPTX / DOCX，含标签持久化、保存态、AI 面板与 ribbon）、笔记与知识库 v1、新标签页 / 多标签栏 / 壳基线、品牌与动效、字号体系、对话展示重写等。本文件只列本轮面向用户的改动，其余只作「一并包含」说明，**不复述行为细节、也不声称已逐一验证**；逐条细节以仓库提交历史为准。

如实说明的边界

- **回归验证的边界（重要）**：本版发布前的门禁只跑了 typecheck 与单元测试，**e2e 没有跑**（按用户明确选择先发版）。因此对话 UI、光标（caret）镜像层、hover 态、打包 asar 排除、Office 预热这些改动的**真实 Electron 回归未覆盖**，风险自担。
- **单元测试**：全量单测结果 **6526 passed / 8 failed / 60 skipped（共 6594）**。8 条里 **7 条是本周期 API 变更后没跟上的过期断言**（office 预加载暴露的 `createBlank` / `sessionSync` / `sessionRestore` 键与 config 必填字段 6 条、`Composer.tsx` 字体类名断言 1 条），另外 **1 条是 `llama-engine` 空闲回收的 flake**（聚焦复跑即通过）。**7 条过期断言已在本版同步修好**（只改测试、不改产品代码）；修复后聚焦复跑 3 个文件 **83/83 passed**，全量没有重跑。
- **一处已知的产品侧文案小 bug（未修）**：`window.kyclaw.office.config()` 在校验失败时抛的文案误用了 `[kyclaw] invalid session restore response`（应为 config 自己的文案）。只影响报错提示、不影响功能，留待下轮修。

- **真机验证待补**：PB-014（caret 对齐）、PB-015（触发器）、PB-016（asar 减包）、PB-017（Office 预热）的**真机验证尚未进行**，将在恢复测试后补做；本版本不把它写成「已完成 / 已验证」。
- **安装包体积是预期值**：141.72 MiB 的排除量来自对上一份 asar 头的逐项实测，但「≈263 MiB」是算术推算，**本版未重新打包**，也没有安装包产物随本次发布。
- **Office 预热的边界**：启动即预热只保证「首帧后尽快开始」，不保证首屏可输入时字体已注册完毕；预估与实际 paint 有偏差时，以真实 paint 记录为准。
