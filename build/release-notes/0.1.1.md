kyclaw 0.1.1

本次更新内容：

模型与渠道

- 同一个端点现在可以登记多个模型：新增时先列出这个端点上有什么（本机服务没配密钥也能列），保存前就能挑；已登记的模型列在展开行里，点一下切换、多余的可以摘掉。
- 渠道可以起显示名（不填仍按预设名 / 「自定义 N」）。改名只影响界面显示，密钥与请求仍按原来的 id。
- 模型的上下文长度可以手填覆盖；下面那行会写明这个数字是「手动」「实测」还是「回退」，一眼看出哪些不是实测值。
- 「测试连接」改成三步分项报告：连通、流式对话、流式工具，每步给出四档结论（通过 / 失败 / 未验证 / 未执行）。拿不到正面证据的一律标「未验证」，冒充成通过是不允许的；某一步没过也不会挡住模型注册。
- 适配了 LM Studio（llama.cpp 系）对工具定义的校验：参数结构必须带 properties、大上限的数组必须同时给下限。此前这类端点在带工具的一轮里会直接报 400。

设置与界面

- 「我的规矩」改名为「约束」，页面去掉面向开发者的内部文案（处理器注册状态、刷新按钮等），只留一个输入框与一句说明；来源只显示项目内的相对位置，完整路径放在悬停提示里。
- 「追踪」加了显式开关：关掉就是一律不上报。开关当场生效；地址、代理、公私钥与「保存」收进展开区，不再平铺在页面上。
- 保存现在有行内反馈（「已保存」）；改动任何一处草稿都会把上一次的反馈收掉，不会出现「内容已改还挂着已保存」。保存期间又改了内容时，这一趟保存不会覆盖你刚敲的字。
- 粘贴图片不再重复：同一次粘贴只入队一份（此前截图工具贴图会出现同一张图两份）。
- 会话根内的文件在界面上显示工作区相对路径，根外的仍显示完整路径。只改显示，发给模型的路径一个字不动。
- 长会话的右侧消息导览轨不再越拉越长：轮次多时行高自动压缩，悬停或键盘聚焦时那一行展开回满行高；当前这一段会自动滚进轨内视野，↑/↓（Home/End）能在轨内逐轮走。
- 「用量」页不再显示花费，只保留 token 用量（总量 / 按模型 / 次数）。历史库里已有的花费列保留不动，只是不再读取。
- 冷启动那几百毫秒里敲下的字不会丢：会话 id 定下来那一下输入卡会重挂一次，草稿的过桥现在以输入框里**真实写着的内容**为准，不再依赖可能还没跟上这一步改动的内部状态。

Agent 与轨迹

- 规划模式与任务清单现在是包含关系：进入规划后任务清单那一格一定在（有没有任务都一样）；＋ 菜单与 `/` 命令里都能进入规划模式，背后是同一个入口。
- 轨迹里新增「这一轮实际发给模型的请求」：系统指令、记忆与约束注入、工具表、逐条消息与后续的工具结果，按**每一步**分别成行，正文点开哪条取哪条（一次请求实测约 96 KB，列表不背它）。
- 用量记账的两处修复：个别的读取失败不再把整页用量拖垮（一律回一句人话）；老版本升级上来的库缺列时会正确补列（此前那条路会让用量页面整块报错）。

更新

- 「设置 → 关于」现在会显示这一版的更新内容，检查更新后就能看到改了什么。说明只显示当前这一版的那一份，按纯文本显示（源上给的 HTML / 脚本按字面量展示，不插进页面、不拉远程图片）；某一版没有提供说明时不显示这一块，检查、下载与安装照旧。
- 换了更新源之后，显示的只会是新源上那一版的说明；旧源那边还没结束的下载与结论不会再混进来。

如实说明的边界

- 模型失败的那一次调用**没有请求正文可看**：接口本身不返回，轨迹只记「这一轮失败了」，不会拿别的内容顶替，那一行会明确标成失败。
- 本机 / 内网服务上的模型只是把工具定义的兼容性实测过，**不代表这个网络里的所有模型都能用**：模型名、上下文长度、能否读图仍以端点实测与注册表为准，拿不到实测的数字会标成「回退」。
