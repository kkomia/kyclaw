kyclaw 0.2.0

本次更新内容：

内核迁移

- 内嵌 Mastra 内核替换为独立 DSH Node 子进程（`@deepseek-ai/*` **v0.2.1-rc.2**）；旧内核整体移除：`src/mastra` **133 个文件**（81 生产 + 52 spec/route）与 **8 个 `@mastra/*` 依赖**全部删除。
- 回滚锚点：tag **`legacy-mastra-kernel` = `02ebf64`**（历史源码点，不随 0.2.0 移动）。

路由面变化

- 0.2.0 下架 **8 条**宿主 API（tasks / goal / projects / ppt / mcp / memory / usage / trajectory，均返回 **501** `feature-disabled`）；`/api/threads` **不是下架**，而是改为由内核 session 承接。合计 **9 条路由面变化 = 8 条下架 + 1 条重实现**。
- 端点级差异单列：`POST /api/threads/:id/truncate`、`POST /api/threads/:id/compact` 带 `keep` 时返回 501；内核未启动时 `/api/threads*` 返回保护性 503；旧 `/plans/*` 5 个 SSE 端点与 `/ask-user/resume` 不再提供（无替代）。

测试覆盖变化

- A2a/A2b 移除 **75 个旧 loop spec**（`src/mastra/__tests__` 73 + `tools/__tests__/approval*` 2；127 spec → 52 spec），生产文件 81 个未动。
- 覆盖归属：44/44 表完成；`read-media` 转内核 read 探针（PB-032），`vision-wire` 转内核 wire 探针（PB-033）；`model-tool-media` 随旧 loop 退场、不再适用；其余由内核侧探针/e2e/既有 main/renderer 测试等价承接。

plan 能力变化

- 旧计划面（`/plans/*` 的正文/批准/修订/继续）已下架；计划能力改为 **DSH plan mode**：`/plan` 进入规划，模型通过 `exit_plan_mode` 提交完整计划，界面出现**计划评审卡**（Markdown 渲染），可选择 **Approve** 继续执行或 **Keep planning + 反馈** 回到规划。**注意：当前内核没有独立「拒绝」语义，拒绝只能表达为 Keep planning**；旧式的计划版本号/修订历史暂无对应，0.2.x 再看。

修复与改进

- **失败轮保留（R11）**：失败轮正文与失败元数据可从内核 inbox splice 恢复；消息流内渲染失败卡，dock 不再重复显示（PB-034 + PB-037）。
- **启动失败恢复**：错误卡提供「重启应用」而非「再跑一次」；有未保存 Office 文档时拒绝重启、不绕过退出守卫（PB-038）。
- **工具轮稳定性**：非文本 block 不再产生无主 `text-end`，修复「先说话再调工具」整轮失败（PB-039）。
- **read_image**：rc.2 快照补齐 `@img/sharp-win32-x64`，打包后 `read_image` 可用（PB-040；验证范围见下）。
- **计划 API 清理**：renderer 不再调用已删 `/plans/*`，消除用户可见 404 错误卡（PB-041）。
- **运行期崩溃可诊断**：写 `kernel.crashed` 日志；后续错误卡带退出码/信号与日志路径（PB-043）。

排障

- 内核日志：`<userData>/logs/kernel.log`（Windows 典型为 `%APPDATA%\kyclaw\logs\kernel.log`）；启动失败/运行期崩溃的 `kernel.start`、`kernel.ready`、`kernel.crashed` 都写在这里。
- 运行期崩溃：日志含 `kernel.crashed`（退出码/signal/时间）；界面错误卡会带「内核进程已退出（exitCode=…）」、重启建议与日志绝对路径。
- 「重启应用」：调用 `app:relaunch`（`app.relaunch()` + `app.quit()`）；有未保存 Office 文档时返回 `unsaved-documents`，不重启也不绕过退出守卫；异常返回 `relaunch-failed`。
- 本地 e2e/CI：若 shell 有 `ELECTRON_RUN_AS_NODE=1`，Playwright 启动 Electron 会报 `bad option: --remote-debugging-port=0`；跑 e2e 前清掉该环境变量。
