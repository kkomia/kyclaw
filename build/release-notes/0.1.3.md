kyclaw 0.1.3

本次更新内容：

对话

- **图片上下文**：用户消息里的图片上下文改为固定 96×96 缩略图、等比完整显示；点缩略图可放大查看（关闭钮 / 点遮罩 / Esc 都能关，焦点不跑丢）。图片不再重复成一条附件文字。
- **发送时间**：鼠标悬停用户消息时，在消息下方显示**裸文字时间**，没有背景气泡、不额外垫高一行；键盘 focus 到消息里也能看到。
- **选文引用**：在 AI 回复里选中文字后右键「引用到输入框」，会变成一张**摘要卡**——60 个字符摘要 + 字数 +「发送含原文」+ 可展开编辑；不会自动发送，输入框也不会被占位；真正发送时带的是**完整原文**。选文只认同一条回复的同一个正文块（块内可跨段落）；跨思考 / 工具 / 交付卡 / 折叠内容不提供引用菜单。
- **文件交付**：本轮所有文件交付卡**统一聚合到整轮回复的最终位置**，不再跟着 deliver 在中间过程段里出现；流式中已经出结果的卡也直接落最终位。去重按真实 `toolCallId`：同一次调用有更新取最新，两个独立调用即使交付同一路径也保留两张卡。
- **回复里的表格**：表格套上圆角外框，可横向滚动；右上角有图标式「复制」与「下载」——复制 / 下载的内容与回复里的 Markdown 原文逐字节一致（文件名取表头第一格）。

网页引用

- 助手正文里的数字引用显示为**上标角标**；点击直接打开来源，悬停（或键盘 focus）弹出摘要卡，显示站点、标题与摘要；Esc、滚动、失焦都会收起。
- 消息末尾动作行的来源入口是一枚 **Globe 图标**，顺序固定为 **复制 → 重新生成 → 单竖线 → 来源**；默认折叠，点一下展开完整来源列表，不出现「引用」字样。
- **来源必须对得上本轮工具结果**：只有本轮**已完成**的 `web_search` / `fetch` 结果里出现过的 URL 才会被认成来源；正文里的数字链接没命中就保持普通安全外链，不进来源列表。跨用户轮不合并。
- **代码示例不误收**：围栏代码（含引用块 / 列表里的）、缩进代码、行内代码、HTML 注释与 reference definition 里的 `[1](url)` 都不会被当成来源。
- 站点标识用**本地字母头像**（认不出字母 / 数字时用 Globe），同一站点颜色稳定；不加载远程 favicon，也没有放宽渲染端 CSP。

权限

- **完全权限下读技能不再绕 bash**：已注册且有效的技能资源可以直接通过 `read` 的 `skill` 参数读取，不再因为技能放在用户目录而被迫走 `bash`、再触发区外审批。读取路径做段级校验与 realpath containment，入口失效即失败；技能图片还有大小、像素与内容嗅探的二次门控，不通过就只退化成文字。
- **没有扩大其他权限**：普通 `read` / `write` / `bash` 的区外口径没变；MCP 的分类与 `outsideWorkspaceMode` 没变——**没有显式标只读的 MCP 工具仍然要审批**。

设置

- **模型编辑布局精简**：模型行内编辑里「渠道名称」独占一行，「模型名称」与「模型 ID」同一行；六个输入框的 placeholder 说明小字全部去掉，模型名称下「只影响显示…」那句也去掉；标签统一为「渠道名称 / 模型名称 / 模型 ID」。添加渠道弹窗同步了标签，没有新增字段，存储语义不变。
- **API Key 显隐**：保存过密钥的输入框在掩码态显示圆点占位；点眼睛会**回显已保存的真实密钥**（不是把圆点清空），再点回到掩码并立即清掉本地明文。回显只由显式点击触发，经主进程安全读取，**不落盘、不写日志、不缓存、不自动推送**；收起行、切渠道、保存、关弹窗、重新输入、卸载都会清掉。未配置或需要重录时如实提示，不假装有 key。

启动

- 启动画面改为**阶段百分比**：20 / 40 / 60 / 80 / 100，分别对应启动壳显示、渲染端入口执行、设置读取完成、首屏 DOM 提交、启动壳退场。只由真实阶段事件推进，**没有定时器补数，也不冒充耗时百分比**；晚到的设置事件不丢、不倒退。
- 启动壳与窗口主题一致（浅色 / 深色 / 跟随系统），尊重系统「减少动效」；启动失败时停在失败态并显示「启动失败，请重启 kyclaw」，不会继续假装加载。

托盘

- 关闭窗口时可以选择**最小化到托盘 / 退出 kyclaw / 每次询问**；弹窗里可勾「记住我的选择，下次不再询问」，只有明确选择且勾选才落盘。选「最小化到托盘」时窗口隐藏、后台对话继续跑；托盘不可用会回退为正常关窗。
- 设置 → 外观 里可以随时改这三档，也能改回「每次询问」。

技能导入

- 插件页现在可以**单独注册一个 Skill**，不必随插件整包安装：支持**网址**（md 直链 / 单技能 zip）、**本地文件**（md / zip）与**本地文件夹**，导入后落在「我的技能」一组。内网地址需要显式放行精确的 `host:port`；压缩包里的路径穿越、炸弹与 junction 会被拒绝。

文件预览

- 图片预览始终**保持原始宽高比**：默认 contain、只缩不放，小图不会被撑大；四边留白 16px；支持可见的 ± 按钮、`Ctrl` + 滚轮缩放、放大后鼠标拖拽平移与旋转。拖拽不会吞掉控件点击，也不接管触摸 / 触控笔；PDF 的文字选文不受影响。

修复

- 修了 **Windows 8.3 短路径**下的交付路径问题：以前交付卡可能显示带 `../../..` 的相对路径，现在路径层统一以 realpath 根计算，`deliver` / `read` / `render-ppt` / `delete` / `move` 都用真实根，交付卡显示正确的相对路径。

如实说明的边界

- **真实网站 favicon 还没有做**：现在用的是本地站点首字母 / Globe，不放宽 CSP、不加载远程图片；真实 favicon 需要主进程代理抓取与缓存，另立。
- **启动主 bundle 加载失败时，启动壳会停在阶段 20%**：目前没有 watchdog 超时兜底，不会自己跳到失败态。
- **没有搬运 DSH 的插件宿主代码**：这次插件页补的是 Skill 的单独注册；插件宿主 / 安装能力的边界与之前一致。
- **API Key 回显的边界**：已保存密钥只在显式点击眼睛时临时回显；收起行、切渠道、保存、关弹窗、重新输入或卸载后立即清除，不会自动推到界面，也不会写日志或落盘。
- **表格复制 / 下载**：下载交给系统下载管理器，只回「已开始下载」，最终存到哪、是否取消应用不跟踪；复制只保证交给系统的字节与 Markdown 原文一致。
