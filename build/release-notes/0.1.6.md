kyclaw 0.1.6

本次更新内容：

新功能

- **goal 目标模式（V1，PB-039）**：每个会话有一个可持久的目标——四种状态（进行中 / 已暂停 / 已阻塞 / 已完成）、目标文案、轮数上限（默认 256）与阻塞原因。模型可用 `get_goal` / `create_goal` / `update_goal` 三件套读写；界面在输入框上方有 36px 的 goal 条（取数、暂停 / 恢复 / 编辑 / 清除），没有 goal 时不显示。
- **斜杠命令与命令面板（PB-039 §1）**：`/` 命令面板按 DSH 数值对齐（面板最高 320、行 5×7/12px、搜索行同规格、方向键 + Enter + Tab/Shift+Tab + Esc）；「指令」一节收录 `/compact`、`/plan`、`/goal`。`/goal` 支持 `create / edit / pause / resume / clear`，控制词必须占满整行，输出六行结果卡片（Status / Blocker / Objective / Rounds / Activation / Commands）。
- **UI 字体改为复用随包 Noto Sans SC（PB-026）**：主界面中文改用安装包里已有的 Noto Sans SC（与 Office 面同一份字体文件），**安装包 0 体积增量**；离线内网机器不再回退系统字体。

修复

- **对话内 Markdown 表格长内容自动折行（PB-025）**：不再出现横向滚动条，允许表格变高、不允许横滚。
- **AI 消息下的操作按钮行与正文左对齐（PB-028）**：与正文同一左基线（共用 `--chat-reading-indent`），hover 胶囊样式不变。
- **轮次失败提示卡与正文同栅格（PB-036）**：图标 / 标题 / 原始错误串 / 按钮按消息列对齐，原始错误收进「详情」，主文案中文化。
- **暂时隐藏「笔记与知识库」「导图」入口（PB-037）**：早期功能不对外；路由与代码保留，可直接访问。
- **窗口控制按钮图标偏大（PB-029）**：图标缩到 10px 细线，36px 热区与间距不动。
- **流式输出中汇总行与工具命令行重叠（PB-030）**：汇总行不再 sticky，滚动时不再压住相邻行。
- **中间轮次正文改为轮末统一显示（PB-031）**：有过程内容（工具/思考）的轮次，流式期间不再有上下两块同时增长互相抢滚动；纯文本回复仍逐字流式。
- **read 工具不能读 `.html` 等文本文件（PB-038）**：`.html/.htm/.css/.js/.ts/.json/.svg/.xml` 等文本型文件按内容嗅探编码后正常读取（UTF-8 / BOM / UTF-16 / GB18030），行号与分页正确；真二进制（zip/exe/wasm/png…）仍明确拒绝并给出下一步提示。
- **复杂长任务误报 stale-run（PB-034）**：给「挂起的审批/提问续跑」加宽限窗口（吸收落库与续跑的时序差），过期/重放仍按原语义拒绝；四处 4xx 响应补上中文人话 `message`。
- **Excel 查找点了没反应（PB-020）**：接上上游真正的查找通道——工具栏「查找」或 `Ctrl/Cmd+F` 打开查找条，输入即时定位并高亮单元格（`findText` + `selectCells`），Enter / Shift+Enter 上下跳、Esc 关闭；区分大小写，单次最多 1000 条命中并提示截断。（0.1.5 里承诺的「下个版本修复」）
- **离线/内网时输入框读数全为 0（PB-027）**、**一轮对话执行中读数不实时（PB-033）**：服务端向模型请求流式 usage，并在流内按步直推精确用量（`data-usage`）；前端优先显示活数据、轮末以落库值为准。**拿不到精确 usage 时显示「—」，不做任何估算**（包括不把 0 当真实值）。
- **Markdown 渲染闪烁（PB-041）**：结束态沿用分块渲染（代码块 / 表格不再重挂），代码高亮模块级缓存，重挂首帧即高亮。
- **失败后「重试」已产出内容丢失（PB-035 C）**：失败前已经产生的正文与工具卡会随那条失败消息一起落库（原错误信息保留），刷新或切换会话后仍能看到。
- **失败轮「重试」不再清空已产出内容（PB-035 B′）**：错误提示卡的主操作改为「保留内容再试」——**新起一轮**继续，旧内容原位保留（不再走"截断 + 整轮重跑"）；「清空重来」收进详情菜单。重试用的续跑消息在界面上不显示为用户气泡。
- **工具执行状态行文案恒定、左侧动画单一（PB-032）**：状态行文案从 2 种扩到 8 个阶段，左侧加载指示器按 DSH 的三种动画轮换（10s 周期），换词带过渡动效。**真机验证**：26s 自注入长流实测采到 `bounce → orbit @9582ms`、`orbit → bounce @19673ms`，间隔 **10091ms**（≈10s 周期），换词动效同时可见。

已知问题 / 边界

- **PB-031 的取舍**：有过程内容的轮次在流式期间**不显示正文**（等全部轮次结束再统一显示）；纯文本回复不受影响。若希望流式中也能看到文字，改回只需一行渲染条件。
- **goal V1 不含**：命令面板与「＋」菜单同源、`/goal` 指令气泡持久化、goal 的恢复 / fork 语义、严格命令校验（这些在 V2 清单）。**goal 自动续跑的 driver 已实现但默认关闭**（待与面板联调验证后再开）。
- **Excel 替换未做**：上游没有 replace API，本版只做查找与定位；替换需要逐格编辑 + 确认语义，属后续条目。
