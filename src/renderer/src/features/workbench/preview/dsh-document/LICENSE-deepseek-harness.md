# 本目录内代码的来源与许可

本目录（`src/renderer/src/features/workbench/preview/dsh-document/`）是 **DeepSeek Harness（DSH）**
同名实现的**适配移植**，逐文件对应关系写在每个文件头注里。

- 上游仓库：`deepseek-harness`（DeepSeek）
- 上游版本：commit `86a402200d95fecef4529d969836f1fe13c6cb0d`
- 上游路径：`packages/client/ui-sidebar-documentpreview/src/client/` 下的 `pdf/`、`zoom/`、`office/`
- 上游许可：**MIT**（全文见下）
